Розрізнені системи

Немає автоматизації

Базові DVR не підтримують розклади для GPIO. Відкрити ворота о 7:00, закрити о 22:00 -- потрібна окрема автоматика.

Можливості

6 ключових модулів системи

🎥

IP-камери (RTSP)

Перегляд потоків Hikvision та Dahua в реальному часі. Налаштування каналу, субстріму, FPS. Конвертація RTSP → MJPEG через FFmpeg.

⚡

GPIO управління

Імпульсний режим для воріт/шлагбаумів (настроювана тривалість) та перемикач для освітлення. Окремі GPIO-кнопки без прив'язки до камер.

📅

Розклади

Автоматичне виконання GPIO-дій по часу. Вибір днів тижня (Пн-Нд). Дії: імпульс, увімкнути, вимкнути. Фоновий планувальник 24/7.

🔍

Мережевий сканер

Автоматичний пошук камер у локальній мережі. Сканування портів 554, 80, 8080. Додавання знайдених камер в один клік.

👥

Мультикористувачі

Ролі Адмін/Користувач. Кожен бачить свій порядок елементів. Індивідуальні налаштування виду (плитка/список, колонки). Авторизація з "запам'ятати мене".

🔃

OTA-оновлення

Перевірка та встановлення оновлень з власного сервера. Автобекап перед оновленням. Діагностика з'єднання. Відкат при помилці.

Встановлення

Запуск за 4 кроки

Від розпакування до працюючої системи -- менше 30 хвилин

1

Підключення

Orange Pi + реле-модуль. Живлення, Ethernet, підключення GPIO до воріт/замків

2

Запуск

Один Python-файл. Запуск як systemd-сервіс. Автостарт при перезавантаженні

3

Налаштування

Через веб: додати камери (або автопошук), створити GPIO-кнопки, налаштувати розклади

4

Працює!

Відкривайте в браузері з телефону чи ПК. Камери, ворота, автоматизація -- все готово
